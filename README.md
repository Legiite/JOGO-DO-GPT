# THE LAST SIN

RPG de horror medieval em português, com escolhas clicáveis, sobrevivência e modo narrador ChatGPT.

**Alpha v0.1.1.** Cada pessoa cria sua própria partida; nenhuma escolha pessoal do criador faz parte do jogo.

- `index.html`: versão jogável no navegador (salvamento local).
- `MODO_CHATGPT.md`: instruções para jogar por conversa com ChatGPT.

## Como jogar
Abra `index.html` no navegador ou publique o repositório pelo GitHub Pages (Settings > Pages > Deploy from a branch > `main` / root). Para jogar com narração por IA, clique em **Jogar com ChatGPT**, copie o prompt preparado e cole em uma conversa nova no ChatGPT. A conversa é independente do salvamento no navegador; não há sincronização automática.

Conteúdo: horror, violência fictícia e mutilações. Projeto experimental em desenvolvimento.
