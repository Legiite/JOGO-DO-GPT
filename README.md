# THE LAST SIN — RPG narrativo com ChatGPT

**Alpha v0.1.1** — fantasia medieval sombria, horror, sobrevivência e escolhas com consequências.

## Como jogar
1. Abra a página inicial do projeto (após habilitar GitHub Pages) ou o arquivo `index.html`.
2. Clique em **Iniciar The Last Sin no ChatGPT**.
3. Envie o texto preparado ao ChatGPT. Se o texto não aparecer automaticamente, use **Copiar instruções** e cole-o numa nova conversa.
4. Crie seu próprio personagem e jogue, com o ChatGPT narrando e oferecendo ações clicáveis quando suportadas.

**GitHub Pages**: no repositório, acesse **Settings → Pages → Build and deployment → Deploy from a branch**, escolha **main** e **/(root)** e salve. Para compartilhar publicamente, será necessário tornar o repositório público (ele está privado no momento).

## Arquivos
- [index.html](index.html): página que abre o ChatGPT com uma mensagem inicial para começar uma partida.
- [MANUAL_DO_MESTRE.md](MANUAL_DO_MESTRE.md): regras de campanha, sistemas e mundo.
- [PROMPT_INICIAL.md](PROMPT_INICIAL.md): instrução inicial para copiar manualmente.

## Limitações da Alpha
Esta é uma experiência **narrativa dentro do ChatGPT**, não uma aplicação com IA própria, nem um gerador de jogo programado automaticamente. O link prepara uma conversa; o usuário precisa enviar a mensagem. O navegador não sincroniza salvamentos com o ChatGPT. A consistência do estado depende do contexto da conversa, portanto é recomendável pedir resumos/exports da ficha em campanhas longas.

As escolhas e a ficha pessoal do criador **não são incluídas** nesta versão.

**Aviso de conteúdo:** horror, violência fictícia e mutilações.
